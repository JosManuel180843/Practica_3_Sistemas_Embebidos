# Practica3_SistemasEmbebidos
Implementación de un contador ascendente y descendente con signo de 9 bits en Verilog para la FPGA Intel DE10-Lite. Incluye reinicio, pausa, selección de intervalos de actualización de 1 segundo y 100 milisegundos, y visualización del conteo mediante cuatro displays de siete segmentos.
